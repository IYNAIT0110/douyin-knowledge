### 一、模型架构 / Agent 工程 —— 最近硅谷热议的 Jev 模型及其影响

- 链接：https://v.douyin.com/YvTf6dg1H90/
- 分享时间：2026-09-21 09:04
- 逐字稿：`transcripts/2026-09-21/7687030616353823355.txt`（7 分 18 秒）
- 知识向：`2026-09-21-Jev决策模型-深度总结.md`｜英语向：`2026-09-21-Jev决策模型-中英对照.md`

**视频主题**
一个刚发布就刷屏硅谷的新模型 **Jev**：它不会聊天、不会写代码、连句子都生成不了，只能做判断——这是 OpenAI RLHF 的共同发明人之一 Diogo Almeida 离职两年后交出的答卷。

**核心观点**

1. **它换的不是能力，是目标函数**。Jev 面向 TypeSafe AI 的 "System One Model"，删掉了全部自然语言生成，只保留三个原语：**Noul（是/否）、Choice（多选一）、Score（打分）**，输出一个标签 + 一个概率。
2. **被病灶在于"用写散文的方式做判断"**。银行客服路由一个投诉，今天要跑完"输入 → 思考 → 流式输出 JSON → 解析"整套仪式，几秒 + 真金白银，而业务只需要一个标签——杀鸡用牛刀。
3. **RLHF 的锅：把人塞进了回路**。RLHF 优化的是"哪个回答人更喜欢"，所以才会有 Let me 举的那个例子——有人给 ChatGPT 发一段放屁录音说是原创音乐，它一本正经地赏析起来。**过度承诺是特性，不是 bug。**
4. **RLCD 优化的是"决策对不对 + 概率诚不诚实"**。校准的含义很朴素：模型说 90% 的那一批判断里，最终大约真有 90% 应验。这是它能被塞进自动化流水线的技术前提。
5. **经济账**：输入 $0.042 / 百万 token，**输出 token 免费**（输出只有一个决策）；自测称提速 20–200 倍、成本降至最高约 1/450。

**关键知识点**

| 项 | 内容 |
| --- | --- |
| 三个原语 | Noul（是/否）、Choice（从给定标准里选一项）、Score（按标准打分） |
| 训练方法 | **RLCD**（Reinforcement Learning for Calibrated Decisions），替代 Diogo 自己发明的 RLHF |
| 延迟 / 价格 | 端到端 70–500ms（典型 ~150ms）；输入 $0.042/M tokens，输出免费 |
| 名字来源 | **杰文斯悖论**：资源越便宜，总消耗反而上升 —— 判断便宜了，人们不会少判，而是到处都判 |
| 理论出身 | **System 1 Model**，来自卡尼曼《思考，快与慢》的快思考 / 慢思考 |
| 关键locution | "Today's AI is incredible at **assistance**, not **automation**." |

**Agent 时代的用法（最值得抄的一段）**

| 达标概率 | 动作 |
| --- | --- |
| ≥ 80% | 直接放行，不进人工队列 |
| 40%–80% | 交给更强更贵的大模型复核 |
| < 40% | 转人工 |

> **人从"盯着每一步"退到"只处理异常"——这才是自动化真正跑起来的分水岭。**

**已有的一周内玩法**：浏览器插件按语义折叠信息流（~380ms/条）、给游戏做输入决策（一秒十次）、清理代码 Agent 的死上下文、7 秒走完机票搜索、LangChain 测试把它当 **Agent 评估器**。

**边界（别急着封神）**：全公司自测数据、无论文无权重无训练数据；"零幻觉"只保证不跳出限定答案类型，不代表不会选错；已有研究者拿出一年前的开源工作做同款思路，学术优先权存疑。

**行动建议**

- 盘点自己工作流里"其实只要一个标签却调用了完整 LLM"的环节，这是立刻能降本提速的一刀
- 给自搭的 Agent 加一层置信度闸门 + 阈值表，别再每一步都人工看
- 建立"便宜判断 vs 昂贵推理"的分层预算意识：要先想清楚这一步是要"想明白"还是只要"做判断"

### 二、技术路线 / 行业格局 —— 解读三种 RSI 的理解

- 链接：https://v.douyin.com/caCeR1Ki3Fg/
- 分享时间：2026-09-19 08:30（**本次补做**）
- 逐字稿：`transcripts/2026-09-19/7685935082942516516.txt`（8 分 19 秒）
- 知识向：`2026-09-21-三种RSI路线-深度总结.md`｜英语向：`2026-09-21-三种RSI路线-中英对照.md`

**视频主题**
RSI（Recursive Self-Improvement，递归自我改进）眼下众说纷纭，作者挑了三家代表性公司——Google DeepMind、智谱、阶跃星辰——逐一拆解它们各自对 RSI 的定义、赌注和背后的动机。

**核心观点**

1. **没人同意 RSI 是什么意思，而这本身就是信息**：每家都在往"对自己资产有利"的方向下定义。
2. **谷歌：缺人 → 用算力补**。Sergey Brin 结束半退休回归主抓 RSI，路径是 **Live/Online RL**（模型一边跑业务一边自我进化，思路接近 TTT）。外界看到的是"六周连发三个 Flash 却没有 Pro"，内部看到的可能是"在线 RL 终于跑通了"。
3. **智谱：连流水线都要自己造**。港股募资约 393 亿港元、六成押 RSI，定义是**完全自训练**——下一代 GLM 在上一代 GLM 搭建的环境里训练，分三件事：**数据资产自净**（自对弈 + 规则校验 + LLM as a judge + 人工抽审）、**环境自造**（智能体采集真实任务、自造验证器）、**基础设施自我优化**（让模型去优化自己的算子/内核/调度/缓存/编译）。
4. **阶跃星辰：不打模型竞赛，先做尺子**。联合北大、港科大推出 **Φ-Bench（Frontier AI Infra Bench）**，问的是"模型能否优化支撑自己运行的基础设施"。结果不理想：Claude Opus 5 也只有 36.53 分，最低模型 13.31 分。

**关键知识点**

| 公司 | RSI 的定义 | 补的短板 | 用的长板 |
| --- | --- | --- | --- |
| Google DeepMind | **在线强化学习（Live RL）**，类似 TTT | 顶尖人才流失 | 算力与资源储备最足 |
| 智谱 | **完全自训练**：数据自净 + 环境自造 + Infra 自优化 | 自主的数据与环境供给 | 现金（~50 亿美元，六成押 RSI） |
| 阶跃星辰 | **Φ-Bench**：先度量"模型能否优化自身 Infra" | 没有统一的 RSI 度量标准 | 联合北大、港科大做学术级基准 |

Φ-Bench 三类任务：**KFC**（Kernel Function Completion，单算子实现与优化）、**LHI**（Long-Horizon Implementation，真实代码库长周期功能开发）、**E2EO**（End-to-End Optimization，给负载与目标但不指定路径的完整系统优化）。10000+ 候选来源 → **85 个**由专家逐项复核确定的高难任务。

**顺走的一份礼包：什么样的模型能做好 Infra 工程？**

Φ-Bench 团队分析完整优化轨迹后总结的三条特质，**这也是今天最可直接迁移的部分**：

1. **谋定而后动** —— 不盲目改代码，先用低成本假设筛选降低每次迭代成本
2. **实验求新知** —— 设计实验控制变量与噪声，让每次失败也产出信息
3. **谨慎下结论** —— 不简单按性能变化归因，主动排除混杂因素

> 这三条不是机器特性，任何工程师做优化都该这么做。**判断一项 AI 研究是否可迁移的试金石：把 AI 删掉之后它还成立吗？**

**行动建议**

- 把上面三条特质抄进日常调试与复盘流程，尤其是"提防把噪声读成信号"
- 用"三问框架"读任何技术战略稿：它**缺什么**？它有什么**别人抄不走**的资产？它定义的目标能不能让后者回答前者？对不上就是 PR，对得上才是战略
- 区分"模型升级"和 **Skill 升级**：第三种 RSI 更像 skill 层面的进化。对个人同理——升级自己的知识库 / 提示词库 / 验证器，可能比等下一个更强的模型见效更快

## 汇总洞察（跨视频共性）

1. **两条视频刚好构成"加一台部材"和"换一条产线"的对照**。Jev 是把模型压扁成一个薄薄的决策层（牺牲宽度换速度与可信度）；三条 RSI 路线是把训练体系整体加厚（数据与环境的自给自足）。**一个做减法，三个做加法**——但目标一致：**降低单位智能的成本**。
2. **Jev 与吴恩达（09-17）遥相呼应**：吴恩达说"瓶颈从能不能做，转移到了做什么"，Jev 说的是同一件事的另一面——当构建成本崩塌后，真正稀缺的是**判断该走哪条路的能力**。而 Jev 恰好把"判断"这件原本人做的事，从慢思考里剥离出来单独定价了。
3. **Φ-Bench 的三条特质，与"Skill 类/km档 gooING"是同一个故事的另一面**：9-11 大李讲"把一本书蒸馏成 Skill"，今天视频里第三种 RSI 讲"把系统中积累的经验沉淀成 skill 写回 Agent"。两者都在说：**经验只有被结构化地固化下来，才算真正沉淀。**
4. **"我最近大量的时间花在了 AI 的闲聊上"是本 Jarvis 最大的浪费** —— 今天两条视频都指向同一个自律要求：① 别用昂贵的方式做廉价的判断（Jev）；② 别把"看到的热点"当成"沉淀的能力"（Φ-Bench 的低分）。**收藏 ≠ 掌握，必须配动手类待办。**
