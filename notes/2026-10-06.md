### 2）发现并修复了一个会天天妨碍使用的缺陷

体检时发现一条规律性的坏损耗：**词形还原会把词尾的"哑音 e"切掉**。

`lemma()` 剥 `-ed` / `-ing` 时直接砍尾巴，`accumulated` 变成 `accumulat`、`produced` 变成 `produc`、`described` 变成 `describ`、`making` 变成 `mak`。这些 key 不是英语单词 → 词典查不到 → **点这些词只会弹出"词库暂未收录"，而这批恰恰是最常用的动词**。

修法不去硬改 `lemma()` 的截断规则（那会误伤 `planned→plan`、`banned→ban` 这类），而是改为**词典说了算**：分词后多给两个候选，看词典里哪个真有释义就用哪个。

```
1) 原 key 有释义         → 用原 key
2) key + "e" 有释义      → 用 key+"e"    例：produc → produce
3) 表面原形有释义        → 用表面原形    例：hundred→hundr → hundred
4) 都不行                → 保留原 key
```

之所以要第 3 级：`hundred` / `tired` 这类词**并不是过去式**，却同样会被砍掉 `-ed`。顺带修掉了。

> ⚠️ 第 2 级的第一个版本判据写松了——只要"key 存在于词库"就接受，而有道对 `produc` 这种拼错词会返回几条例句却没有释义，于是它照样胜出。改成**必须真的有释义**才算数，过度纠错（`designe` / `aske` / `hundre`）随之消失。
