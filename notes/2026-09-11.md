> 这是一期手把手教程：如何把"一本书 / 自己的某项技能"蒸馏（distill）成一个可复用的 Skill，让 AI 直接调用。

#### 核心观点（提炼自逐字稿）

1. **"蒸馏 = AI 时代的合法抢劫"**
   作者把蒸馏（distill）定义为"把书 / 技能制作成 Skill 的过程"。一旦把高价值内容做成 Skill，就能反复为自己所用——别人读完一本书只能记个大概，你蒸馏出来能直接让 AI 调用。

2. **要蒸馏什么，取决于书的类型**
   - **工具书** → 蒸馏**方法论**（遇到问题直接套用）
   - **非工具书** → 蒸馏作者的**思维框架**（遇到问题用作者的思考方式去找答案）
   - 这个"目标导向"决定了你用什么 prompt、产出什么 Skill 形态。

3. **可蒸馏的对象不止书**
   凡是"能给你提供方法论或思维框架"的原材料都可以蒸馏：**论文、会议纪要、访谈记录**等等。

4. **作者自研的「一展神灯」Skill（基于开源「仓节」skill 改进）**
   | 对比项 | 仓节（Cangjie）Skill | 一展神灯 Skill |
   |--------|---------------------|-----------------|
   | 适用前提 | 必须已经读懂这本书、且有相当认知 | 无需先读懂，AI 会先阅读+整理 |
   | 定位 | 重型工具 | 小白友好型 |
   | 适配环境 | 通用 | 专为 WorkBuddy 环境适配 |

   - **蒸馏操作流程**：去作者知识库下载 skill 文件 → 发到 WorkBuddy 对话窗口让它自安装 → 上传需要蒸馏的原材料（书/论文/会议纪要/采访稿）→ 等 AI 输出蒸馏结果。

5. **蒸馏"自己的技能"为 Skill 的四步法**
   - **第一步**：在任意 AI agent 里与 AI **共同完成一项任务**
   - **第二步**：让 AI **总结完成这项任务所经历的所有工作环节**
   - **第三步**：让 AI 把工作环节中**最有价值的那部分整理成一个 skill**
   - **第四步**：让 AI 给 skill **加入"成长功能"**——每次使用都会自动调优、越来越好用

#### 关键知识点

| 概念 | 含义 |
|------|------|
| **蒸馏（distill）** | 把高密度知识载体（书/论文/技能）提炼为可调用的 Skill |
| **方法论 vs 思维框架** | 工具书蒸馏前者（拿来即用），非工具书蒸馏后者（用作思考脚手架） |

> 访谈类节目的一个剪辑片段，嘉宾来自某金融 AI 搜索公司，讨论 AI 应用公司的"垂直壁垒"——脏活累活（Dirty Work）。

#### 核心观点（提炼自逐字稿）

1. **垂直壁垒二：Dirty Work（脏活累活）**
   嘉宾把"脏活累活"列为 AI 应用公司第二个垂直壁垒。脏活累活不是花哨算法，而是**底层数据清洗、管道建设**这种"看不见的活"。

2. **RAG 质量拉开差距**
   同样调用一次搜索接口（RAG），不同公司返回的 10 条结果的**准确率和相关性**差异巨大。能否高于通用 Web Search 的效果，考验的是公司的"底层技术设施建设"。

3. **数据管线把"客观信息"和"主观观点"区分开**
   - **客观信息**（如英伟达下午 3:10 的股价）：大家看到一模一样，不存在歧义，可直接用于结论。
   - **主观观点**（如投资观点）：天然带歧义，需要做交叉验证、看观点分布。
   同一段文字被管线区分后，会走**不同的下游推理路径**——这条管线是壁垒。

4. **事件重要性分级**
   哪些事件是"critical"、哪些是"小影响面"，由上游复杂的数据工作流驱动。AI 能解决一部分，但**dirty work still matters**，因为它在**推理效率**上有很大优势。

5. **推理效率的辩证（市场上 debate 的观点）**
   - **实时任务**（10 分钟后要开会，PPT 没做好）：越快越好，效率敏感。
   - **长效智能体（Long-running Agents / "赛博牛马"）**：可能连续跑一两天；这种任务下，效率没那么重要。
   - **但**对时效性高的任务而言，提效率 = 省推理成本 + 改善体验，是双重加持。

6. **"脏活前置"换"实时省力"**
   因为底层把脏活累活都做了，运行时就不需要再实时跑那些"脏的活"（分类、归类、推理）。
   - 例子：**Harvey**（法律 AI）—— 底层已对法条做巨类归类 + 总结分论点，接到任务时不需要实时去做查法条等耗时操作，能快速产出。

#### 关键知识点

| 概念 | 含义 |
|------|------|
| **Dirty Work（脏活累活）** | 数据清洗、归类、打标、汇总分论点等"看不见的活"；AI 应用公司的核心壁垒之一 |
| **RAG 质量** | 同一 query，10 条结果的准确率/相关性；底层取决于技术设施 |
| **客观信息 vs 主观观点** | 前者直接可结论（事实数据），后者需交叉验证（观点分布） |
| **Long-running Agents（长效智能体 / 赛博牛马）** | 长时间（小时～天）持续工作的智能体，对推理延迟相对不敏感 |
| **Harvey 案例** | 法律 AI 通过"底层脏活（法条归类）"换"实时快速产出" |
